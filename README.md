Enterprise MRP Engine & Inventory System

Full-stack Material Requirements Planning (MRP) system engineered to automate inventory tracking, Bill of Materials (BOM) multi-level linking, and net purchasing calculations.


## Tech Stack
- **Backend:** Java, Spring Boot, Spring Data JPA, Hibernate
- **Database:** MySQL
- **Frontend:** JavaScript (Fetch API), HTML5, CSS3 (Glassmorphism)
- **Tools:** Maven, Git, Postman, ngrok

---

##  Core Features
- **Real-Time Inventory:** Track stock, lead times, and components.
- **BOM Linker:** Multi-level parent-child component mapping with required quantities.
- **MRP Explosion Engine:** Automated gross-to-net calculations and procurement action triggers.
